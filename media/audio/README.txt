REPLACEABLE AUDIO FOLDER

The included MP3 files are one-second silent placeholders. Replace them with:
- background-music.mp3 (soft piano/orchestral track; loops)
- applause.mp3
- celebration.mp3
- speech.mp3 (optional narration of the full speech)
- envelope.mp3

Use legally owned or licensed audio. Keep the same filenames to avoid changing code.
For good web performance, compress music to roughly 128-192 kbps MP3.
